# ملفات الهوية الرسمية

الملفات هنا مأخوذة من التصميم المعتمد للأسبوع العلمي السابع. النظام يستخدمها
كما هي، ولا يعيد تصميمها ولا يولّد أي خلفية بالذكاء الاصطناعي.

| الملف | الاستخدام | المواصفات |
|---|---|---|
| `invitation-template.png` | خلفية بطاقة الدعوة | **1080 × 1920** بكسل |
| `mtc-logo.png` | شعار الكلية العسكرية التقنية | مقتطع من التصميم |
| `week-logo.png` | شعار الأسبوع العلمي السابع | مقتطع من التصميم |

## تحديث الأصول من تصميم جديد

```bash
node scripts/prepare-brand.mjs "<مسار التصميم الجديد>"
```

السكربت يعيد القياس إلى 1080×1920، ويقتطع الشعارين، ويطبع ألوان الخلفية حول
شريط الاسم لمساعدتك على الضبط.

## ضبط موضع الاسم

التصميم المعتمد يحمل كل النصوص الثابتة مطبوعة عليه، فلا يُرسم فوقه سوى اسم
المدعو. ولأنه يحمل أيضًا اسمًا نموذجيًا، يعيد المولّد بناء شريط الاسم من
الخلفية المجاورة قبل الكتابة.

القيم الحالية في `src/lib/template-config.ts`:

```ts
export const NAME_BAND = {
  top: 664,          // بداية الشريط المُعاد بناؤه
  bottom: 834,       // نهايته — قبل أول سطر من نص الدعوة
  left: 200,
  right: 880,        // محصور أفقيًا كي لا نمسّ زخارف الحافة اليسرى
  sampleAbove: 661,  // صفّ نظيف فوق الشريط تُؤخذ منه الخلفية
  sampleBelow: 836,  // صفّ نظيف تحته
  feather: 70,       // تمويه الحافتين كي لا يظهر حدّ للرقعة
};
```

### إن تغيّر التصميم

1. شغّل `prepare-brand.mjs` على الملف الجديد.
2. افتح المنصة، أنشئ دعوة تجريبية، وفعّل **شبكة القياس** في صفحة المعاينة.
   تظهر شبكة كل ١٠٠ بكسل بأرقامها، مع مستطيل أخضر يحدّد شريط الاسم الحالي.
3. اضبط `NAME_BAND` بحيث يقع الشريط في الفراغ بين الفاصل الذهبي ونص الدعوة.
4. تأكد أن `sampleAbove` و`sampleBelow` يقعان على صفّين **نظيفين تمامًا**.

> نقطة تستحق الانتباه: الفاصل الذهبي في التصميم له حافة داكنة أسفله تمتد صفّين
> أو ثلاثة. أخذ العيّنة منها يمدّ تلك الحافة على كامل الشريط فيظهر مستطيل داكن
> تحت الفاصل. ابتعد عن الفاصل بأربعة صفوف على الأقل.

لقياس الصفوف النظيفة آليًا:

```bash
node -e "
const sharp=require('sharp');
(async()=>{
  const W=1080;
  const {data}=await sharp('public/brand/invitation-template.png').raw().toBuffer({resolveWithObject:true});
  for(let y=560;y<=900;y++){
    let bright=0;
    for(let x=200;x<880;x++){const i=(y*W+x)*3;
      if(0.2126*data[i]+0.7152*data[i+1]+0.0722*data[i+2]>110) bright++;}
    if(bright>8) console.log('محتوى عند y='+y);
  }
})();"
```

## ملاحظات

- الاسم يُرسم كنص حقيقي فوق الصورة، لا كصورة مولّدة، فيبقى حادًّا عند أي تكبير.
- الأسماء الطويلة تُصغَّر تلقائيًا ثم تُلفّ على سطرين بحد أقصى — لا تُقصّ أبدًا.
- أرقام الهواتف لا تُطبع على البطاقة إطلاقًا.
- إن حُذف `invitation-template.png` يعمل النظام بقالب احتياطي بألوان الهوية،
  مع تنبيه واضح في صفحة المعاينة.
